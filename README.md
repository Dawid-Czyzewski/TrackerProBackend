# TrackerPro Backend

Backend aplikacji TrackerPro — systemu do zarządzania aplikacjami o pracę, budżetem wakacyjnym oraz oszczędnościami.

## Zakres

- REST API dla aplikacji TrackerPro
- autentykacja JWT z refresh tokenami
- rejestracja z weryfikacją e-mail
- moduł aplikacji o pracę
- moduł budżetu wakacyjnego
- moduł oszczędności
- walidacja danych i ochrona endpointów
- testy jednostkowe i integracyjne (PHPUnit)
- konteneryzacja Docker

## Technologie

- Symfony 7.4
- Doctrine ORM
- Lexik JWT Bundle
- Nelmio CORS Bundle
- PHPUnit
- Docker

# TrackerPro Backend

Backend of the TrackerPro application — a system for managing job applications, vacation budget, and savings.

## Scope

- REST API for the TrackerPro application
- JWT authentication with refresh tokens
- registration with email verification
- job applications module
- vacation budget module
- savings module
- data validation and endpoint protection
- unit and integration tests (PHPUnit)
- Docker containerization

## Technologies

- Symfony 7.4
- Doctrine ORM
- Lexik JWT Bundle
- Nelmio CORS Bundle
- PHPUnit
- Docker
